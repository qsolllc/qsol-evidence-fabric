# QSOL Evidence Fabric V1

Status: DRAFT

This repository defines the QSOL Evidence Fabric protocol and its
conformance requirements.

The initial conformance profile is:

QSOL-FIBONACCI-EVIDENCE-V1

Protocol authority is defined by the normative specifications in
`specification/` and their deterministic test vectors in `vectors/`.

No implementation is authoritative merely by virtue of being the
reference implementation.
